## Tableau Project - Superstore USA Analytics Dashboard
Interactive dashboard analyzing Sales, Profit Margin, and Return Rate across categories, sub-categories, regions, and segments.

**Key Insights:**
- Technology leads sales by category (36.4%)
- Consumer segment contributes 50.56% of total sales
- Total Sales: ₹2.30M | Profit Margin: 12.47% | Return Rate: 5.91%
